# pgnode_viewer

`pgnode_viewer` is a visualizer for PostgreSQL query trees and plan trees.

It converts PostgreSQL debug logs into an interactive HTML visualization, allowing you to easily explore complex node structures, attributes, and relationships.

This tool is generated by Claude.

## Features

- **Interactive Tree Navigation**: Expand or collapse nodes, zoom, and pan through large query and plan trees.
- **Smart Filtering**: Hide unneeded default/empty values (`0`, `false`, `-1`, `NULL`, empty) to keep the view clean.
- **Dual Support**: Supports both parse/query trees and execution plan trees.

## Usage

### 1. Setup PostgreSQL Logging

Enable the required debug parameters in your PostgreSQL session to output query and plan trees to your log file:

```sql
SET debug_print_parse = ON;
SET debug_print_plan = ON;
SET debug_pretty_print = ON;

```

### 2. Prepare the Log File

Capture the log output when you execute queries.

An example log file is provided in the `example/` directory:

```bash
$ cat example/sample.log
2026-10-16 14:39:44.348 UTC [72660] LOG:  parse tree:
2026-10-16 14:39:44.348 UTC [72660] DETAIL:     {QUERY 
     :commandType 1 
     :querySource 0 
     :canSetTag true 
     :utilityStmt <> 
     :resultRelation 0 
     :hasAggs false 
     :hasWindowFuncs false 
     :hasTargetSRFs false 
     :hasSubLinks false 
     :hasDistinctOn false 
     :hasRecursive false 
     :hasModifyingCTE false 
     :hasForUpdate false 
     :hasRowSecurity false 
     :hasGroupRTE false 
     :isReturn false 
...snip...
```

Note: While this example contains only one query, the tool can handle multiple queries within a single log file.


### 3. Generate the HTML Visualization

Run the script by passing the log file as an argument:

```bash
$ python pgnode_viewer.py example/sample.log
2 logs was dumped / 34 nodes -> example/sample.json, example/sample.html
```

This will generate an interactive HTML file alongside a JSON file in the same directory:

```bash
$ ls -1 example/
sample.html
sample.json
sample.log
```
Open `sample.html` in your web browser to explore the trees interactively.
